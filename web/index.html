How this works

  1. Split the addressYour browser finds its transparent receiver (t1, t3, TEX or a unified address's transparent part) and any shielded receivers (Sapling, Orchard; Ironwood pays the Orchard receiver).
  2. Read the transactionIt asks Blockchair for the transaction, sending only the txid.
  3. Transparent match?If an output pays your transparent receiver, the exchange paid the transparent part. The amount and address are public.
  4. Otherwise, which poolIt reads which shielded pool the transaction put value into, and how much when the ZEC came from a transparent wallet. The chain doesn't show who received a shielded payment, so the page doesn't claim it: your wallet will show whether it was yours.

No keys of any kind, no viewing keys, no account, nothing stored.

What others can see

  • Blockchair sees the txid you check and your IP address. Use Tor or a VPN if you'd rather it didn't.
  • The address you type never leaves this page: it is not sent, stored or put in a link.
  • A share link carries only the txid. Whoever opens it sees the transaction's pool facts, not your address.
